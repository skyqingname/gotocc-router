# 管理员使用记录界面

`/admin/usage` 沿用 GoToCC `0.2.18+custom.002`（`84e723ed9`）的连续页面布局：

- 顶部四张统计卡，下方为日期范围、粒度和两行分布/趋势图。
- 用量明细接在图表下方，页内使用下划线标签切换明细类型。
- 使用实色卡片和带横向分隔线的普通表格，不拆成「图表统计 / 用量列表」工作区，不使用每行圆角边框。

外观限定在 `frontend/src/views/admin/UsageView.vue` 的 `#admin-usage` 内。
侧栏、顶部导航、用户使用记录及其他页面继续使用当前外观，共享图表和表格组件不回退。

保留当前版本的实时请求、筛选、排序、分页快照、列设置、导出、用户排行、错误详情和客户端中断记录。
管理员服务端点、金额口径、接口和数据库结构保持当前契约。自动刷新沿用当前读取状态保护，并识别页面滚动容器。

此调整不改变版本身份或上游基线；正式发布与生产更新分别按发行流程执行。
